# 침식 프로토콜 — 설계·정책 문서

밸런스 수치와 시스템 규칙의 단일 출처. 코드(`game.js`)와 불일치 시 코드가 우선하며 본 문서를 갱신한다.

## 코어 (승패 축)

- HP 1000 (`coreMax`), 중앙 2×2 타일. 코어 위 월드 HP바 **상시 표시**
- 피격: 배너+비프(4초 스로틀)+비네트 펄스+미니맵 점멸(1.5초)
- 단계 경보(1회성): 50% "손상 심각" / 25% "위험" — 조인 측도 state diff로 동일 발화
- 코어 0 → 즉시 패배. 그 외 패배: 전 유닛 무력화, 다운 40초 경과(구조 실패)

## 웨이브 정책

| 항목 | 규칙 |
|---|---|
| 웨이브 수 | 기본 10 (URL `?waves=` 4–15) |
| 준비 시간 | 기본 40초 (URL `?buildtime=` 15–60), 첫 웨이브 +10초 |
| 마릿수 | `14 + 6w` (물량형 스웜 밸런스) |
| 스폰 간격 | `max(0.24, 0.7 − 0.035w)` 초 |
| 구성(쿼터 보장) | 거너: w≥2에서 `max(3, 22%)` · 브레이커: w≥3에서 25% · 잔여 러셔 · 셔플 |
| 보스 | 웨이브 5 = 중간 보스, 최종 웨이브(기본 10) = **최종 보스** (HP ×10, 모델 2배) |
| 적 체력 배율 | `(1 + (w−1) × 0.18) × 난이도` |
| 적 피해 배율 | `1 + (w−1) × 0.05` (대인·대구조물·코어·원거리탄 공통, W10 = 1.45×) |
| 난이도 | 로비 선택기(쉬움/보통/어려움/악몽) 또는 `?diff=`. 배율 — HP·속도·피해: 0.75/1/1.35/1.49 · 마릿수: 0.8/1/1.25/2.5 · 스폰 간격: 1.15/1/0.88/0.5. 호스트 설정이 방 전체 적용 |
| 악몽 균열 | 동시 활성 균열: 솔로 2개(랜덤 상이), 멀티 4개 전부. 스폰은 활성 균열 중 랜덤 선택. 그 외 난이도는 1개 |
| 아이템 인벤토리 | 최대 5칸(INV_MAX). E/아이템 버튼 → 레이어에서 선택 사용. 멀티: 픽업·사용 호스트-조이너 동기화 |

## 경로 AI — 소프트락 불가 보장

- 코어 기준 Dijkstra flow field (Dial 버킷 큐). 벽/포탑 통과 비용 +24 → 우회가 싸면 우회, 막히면 파괴
- **완전 봉쇄 불가**: 플레이어 구조물은 '통과 비용'일 뿐 차단이 아니다 — 코어를 벽으로 완전히 둘러싸도 경로 거리는 유한하고, 적은 가장 싼 벽을 부수며 전진한다 (전 게이트 경로 유한성 + 30초 시뮬 파괴 진행 테스트로 검증)
- ~~라운드별 침식 암석~~ — 플레이 불편으로 **제거됨** (occ=5 처리 코드는 하위 호환용으로 유지)

## 성장 정책

- XP 필요량: `45 + 30 × 레벨` (XP는 팀 공유 — 호스트 xpTotal을 state로 동기화, 카드는 각자 선택)
- 카드 시트 노출 정책: 준비 단계 = 자동 오픈 / 습격 단계 = 하단 펄스 배지로 보류(클릭 시 오픈), 준비 단계 진입 시 자동 오픈. 대시: 0.18초 무적 돌진(×3.4), 쿨 3.5초
- **시너지**: 카드 2계통 조합 시 1회성 각성 (5종 — 가이드 참조). 카드 UI에 각성 임박 힌트, HUD 하단 배지 표시. 본인 스탯에만 적용(멀티: 각자 로컬)
- 연구(SHOP): 구매자 본인 지갑 차감. 구조물 계열 효과는 팀 전역 배율
- 웨이브 보너스: `30 + 12w`. 처치 자원은 회수 장치 배율 적용

## 네트워킹

- **전용 릴레이 (1순위)**: Cloudflare Workers + Durable Object (`relay/`, `q-erosion-relay.qpoiop3.workers.dev`). 방 코드당 DO 1개, WebSocket 허브. 실측: 매칭 1.2초, 이벤트 전파 ~82ms
- **과금 방어**: SQLite 클래스 DO(무료 플랜 호환) · WebSocket Hibernation(유휴 duration 과금 0) · 방당 소켓 2개 하드캡+역할 중복 거부 · 소켓당 60msg/s 제한(초과 시 종료, 정상 피크 ~25/s) · 메시지 8KB 캡 · 방 TTL 2시간 알람 · 경로 정규식 불일치 시 DO 미인스턴스화
- **폴백 (2순위)**: 릴레이 5초 내 연결 실패 시 공개 MQTT (emqx → hivemq), 토픽 `dc-erosion/v3/<방코드>`
- 호스트 권위: 적 스폰/AI/피해 판정/자원/웨이브 전환. state 패킷 0.13초, struct 패킷 1.4초(변경 시 즉시)
- 조인: 포즈·사격 전송, 로컬 예측 렌더. 건설/구매/판매는 호스트에 요청(bld/buy/sel)
- 진행도(건설 게이지)는 양측 로컬 틱 + struct 패킷 전방 보정
- **일시정지**: 탭 백그라운드 시 pose/state 패킷의 bg 플래그로 전파 — **양쪽 모두 동결**, 복귀 시 자동 재개. 솔로는 증강 시트/백그라운드 모두 완전 정지
- **재접속**: 전송층 자동 재연결(릴레이 1.5초 재시도/MQTT 3초). 조인 이탈 후 같은 방 코드로 재입장 가능(호스트가 유휴 슬롯에 welcome 재발급). 호스트 5초 무응답 시 조인은 동결+대기 배너, 패킷 재개 시 자동 복귀

## 클라이언트/배포 정책

- PWA: 앱 셸 network-first(배포 즉시 반영) · 버전 고정 CDN cache-first · 오프라인 솔로 가능
- 배포: `development` 작업 → `production` PR 병합 → GitHub Actions → Cloudflare Pages (`q-erosion.pages.dev`)
- WebGL 불가 시 안내 오버레이 + 로비 복귀. 참가 무응답 12초 힌트. 방 정원 2인(초과 busy)
