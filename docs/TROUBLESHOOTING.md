# 트러블슈팅 사례집 — 이슈, 원인, 그리고 배운 것

실전에서 겪은 사고의 원인 분석. 각 항목: 증상 → 근본 원인 → 수정 → 재발 방지 규칙.

## 1. 렌더/3D

### 대량 처치·보스 스폰 순간 0.2~0.6초 프리즈
- 원인: 아이템/보스 메시가 런타임에 **PointLight를 추가** → 씬의 라이트 수가 바뀌면 three.js는 **모든 머티리얼의 셰이더를 재컴파일**
- 수정: 라이트 대신 이미시브 헤일로. 규칙: **런타임 라이트 변경 금지** (ARCHITECTURE 렌더 원칙)

### 첫 대량 전투에서 1프레임 스톨
- 원인: 파티클 머티리얼이 첫 렌더 시점에 셰이더 컴파일
- 수정: 인트로 카운트다운 뒤에서 풀 전체 선컴파일(_warmFx). 규칙: **새 머티리얼은 반드시 워밍 경로를 거친다**

### 스킨드 모델이 사각형 덩어리로 렌더
- 원인: gltf-transform의 simplify/quantize가 스킨 정점 데이터를 파괴
- 규칙: **스킨드 GLB에 simplify/quantize 금지**, 정적 모델만 최적화

### 모델이 콩알만 하게 나옴 (코어 교체 때)
- 원인: `_normalize`가 스케일을 루트에 베이크하는데 렌더 루프가 `setScalar`로 **덮어씀**
- 규칙: 정규화된 모델은 베이스 스케일(s0)을 보존하고 상대 배율만 곱한다

### meshopt GLB 로드 실패
- 원인: r147 GLTFLoader에 meshopt 디코더 없음
- 규칙: 에셋 파이프라인에서 `--compress false` 고정. 신규 GLB는 로드 스모크 테스트 필수

## 2. 오디오
### 후반 지속 끊김 — "죽으면 멀쩡해짐"
- 원인: 피격마다 `_beep`이 OscillatorNode+GainNode 생성 → 포위 시 초당 수십 노드 → 오디오 스레드+GC 경련
- 수정: 전역 비프 예산(180ms당 6회). 규칙: **사운드는 이벤트당 발사가 아니라 예산제**

## 3. 넷코드
### 방 생성 후 가끔 매칭 실패
- 원인: 한쪽이 릴레이 타임아웃으로 MQTT 폴백에 **영구 고착** → 상대(릴레이)와 채널 불일치
- 수정: 폴백 중 4초마다 릴레이 복귀 + 매치메이킹 중 보조 MQTT 병행. 규칙: **폴백은 반드시 복귀 경로를 가진다**

### 조이너 연구 클릭 무반응 (배포 직후)
- 원인: 프로토콜 변경(gup 제거) 후 구버전-신버전 혼재 — 구버전 호스트의 응답을 신버전이 무시
- 수정: PV 핸드셰이크 + 불일치 배너 + SW 강제 업데이트 체크. 규칙: **와이어 포맷 변경 = PV 범프**

### 재시작 후 연구 먹통 / 재접속 후 1라운드·건물 소실
- 원인: 게임 요소 재사용 시 넷 스코프 상태(_peerBuys·침투 플래그) 미초기화 / 미드게임에 흘러든 restart가 리셋 유발
- 규칙: **_reset은 게임 간 상태의 완전한 목록을 소유한다**, 상태 전이 메시지는 유효 페이즈를 가드

### 호스트 고연사 시 조이너 버벅
- 원인: 명중·거너탄이 **발생당 1메시지** + 레벨업 연출이 패킷마다 발동
- 수정: 큐→플러시 배칭(hitQ/ebQ), 연출 스로틀. 규칙: **모든 반복 이벤트는 큐에 쌓고 틱당 플러시**

## 4. 게임 로직
### 관통 빌드가 보스를 순삭
- 원인: 관통탄이 **겹친 프레임마다 같은 적을 재타격** (100뎀 탄이 한 적에 219뎀)
- 규칙: 투사체는 대상별 1회 판정(hitIds). 밸런스 조정 전에 판정 버그부터 의심

### 시뮬 페이즈 전이 중 잘못된 분기
- 원인: 틱 중간에 phase가 바뀌었는데 후속 분기가 무조건 `else`로 잡음
- 규칙: 페이즈 분기는 전부 명시적 `else if (phase === X)`

## 5. 클라이언트 수명주기
### 유저가 계속 구버전을 봄
- 원인: 며칠씩 살아있는 모바일 탭/PWA는 리로드가 없다
- 수정: 10분/포그라운드 복귀마다 SW 업데이트 체크 + 로비 빌드 SHA 표기. 규칙: **업데이트는 밀어넣고, 버전은 눈에 보이게**

### 상용에서 일부 유저만 옛 3D 모델을 봄 (빌드는 최신)
- 원인: SW가 /assets/를 **cache-first(무재검증)**로 캐싱하는데, 과거에 char.glb가 **같은 파일명으로 내용 교체**된 적 있음 — 그 창에서 캐싱한 기기는 영원히 옛 파일
- 수정: 캐시 이름 v2로 범프(전체 퍼지) + /assets/를 stale-while-revalidate로 전환
- 규칙: **에셋은 내용이 바뀌면 파일명도 바뀐다** (교체가 필요하면 새 이름 + 매니페스트 갱신), 캐시 전략은 자가 치유형(SWR)만 사용

### 백그라운드 복귀 후 그림자가 옛 위치에 남음
- 원인: 숨김 탭에서는 워치독(2Hz, dt .05)이 틱을 대신하는데 이 50ms가 프레임 시간 EMA에 들어가 **저사양 모드가 백그라운드에서 오탐 래치** → shadowMap.autoUpdate=false로 그림자 동결 → 복귀 시 옛 실루엣 잔존
- 수정: ① document.hidden 동안 EMA 미갱신 ② 저사양 모드에서도 그림자 0.5s마다 강제 갱신 ③ 복귀 시 EMA 리셋 + 즉시 그림자 갱신
- 규칙: 성능 판단 입력은 실제 렌더 프레임만 — 절전/워치독 프레임은 코스트가 아니다
