# 침식 프로토콜 — 게임 가이드

2인 협동 기지 방어 게임. 4개의 균열에서 몰려오는 침식체로부터 중앙의 **정화 코어**를 지켜라.

- 플레이: https://q-erosion.pages.dev
- 모드: 싱글 플레이(AI 봇 동료 유닛-B) · 2인 온라인(4자리 방 코드, 무료 릴레이)

## 목표와 승패

| 조건 | 결과 |
|---|---|
| 설정된 웨이브(기본 15)를 모두 방어 | **탈출 균열 개방** — 침투 작전 시작 |
| 침투(맵 2)에서 침식의 근원 처치 | **최종 클리어** — 엔딩 크레딧 |
| 정화 코어(HP 1000, 증강으로 확장 가능) 파괴 | **패배** — 코어 위 HP바 상시 표시, 50%/25%에 경보 |
| 두 유닛 동시 무력화 · 40초 내 구조 실패 | **패배** |

쓰러진 동료 곁에 **2.5초** 머무르면 부활한다.

## 조작

| 플랫폼 | 이동 | 대시 | 아이템 | 기타 |
|---|---|---|---|---|
| PC | WASD/방향키 | Space | E | 마우스: 건설 배치 |
| 모바일 | 화면 드래그(가상 스틱) | 대시 버튼 | 아이템 버튼 | 자동 조준 |

사격은 자동 — **사거리(기본 9)** 내 가장 가까운 적을 조준하고, 투사체도 사거리에서 소멸한다. 연구 '조준 광학'(+12%×5)으로 확장.

**대시**: 바라보는 방향으로 0.18초 고속 돌진(이속 ×3.4)하며 **돌진 중 완전 무적**. 기본 쿨다운 3.5초.
포위 탈출, 적 탄막 회피, 쓰러진 동료에게 급행할 때 사용. 연구 '대시 모듈'(−20%×4)과 시너지 '전투 기동'(−25%)으로 쿨다운 단축.

## 게임 흐름

1. **준비 단계** (기본 40초, 첫 웨이브 50초) — 건설·연구. `습격 즉시 개시`로 스킵 가능
2. **습격 단계** — 균열에서 침식체 스폰. 전멸시키면 다음 준비 단계로

## 건설 (건설 버튼)

| 구조물 | 비용 | 내구 | 건설 시간 | 역할 |
|---|---|---|---|---|
| 벽 | 10~ | 140 | 1.2초 | 경로 차단 — 적이 부수거나 우회 |
| 포탑 | 30~ | 90 | 2.5초 | 자동 요격 (완성 전 비활성) |

건설 비용은 웨이브가 오를수록 +8%/웨이브(최대 2.5배)로 상승 — 후반 자금 인플레 흡수. '건설 자동화' 연구로 상쇄 가능.

- 건설 중 구조물은 게이지가 차오르며 완성 시 효과 발생
- 판매: 비용의 70% 회수
- 피해를 입은 구조물은 머리 위 HP바 표시 (시안→앰버→적색)

## 적 유형

| 유형 | 특징 |
|---|---|
| 트라이 러셔 (원뿔) | 근접 돌격, 다수 |
| 큐브 브레이커 (상자) | 구조물 특화 — **경로가 있어도 인접 구조물을 부순다** (웨이브 3+) |
| 헥스 거너 (육각+링) | **원거리** — 거리를 유지하며 투사체 사격 (웨이브 2+) |
| 보스 | W5 **중간 보스** · W10 **대형 보스**(HP 4배) · W15 **최종 보스**(HP 14배 · 구조물을 2배 위력으로 부순다 — 벽 미로가 순식간에 뚫리니 화력 집중 필수) |

웨이브가 오를수록 수·체력(+18%/웨이브)·**속도(+7%/웨이브, 15웨이브에 약 2배)**가 증가한다 (11웨이브부터 마릿수 증가는 완만).

## 성장

### 레벨업 — 강화 카드 3택1

- **트리거**: 경험치(처치 시 획득, 팀 공유)가 `45 + 30×레벨` (+Lv6부터 레벨당 12 추가)에 도달하면 자동 레벨업 (상승음)
- **솔로**: 카드 시트가 화면 전체 오버레이로 열리며 **게임 전체가 일시정지** (웨이브 타이머·적·탄환 모두 정지). 선택하면 재개
- **멀티**: 준비 단계엔 자동 오픈, 습격 중엔 `⬆ 강화 카드 n` 펄스 배지로 보류 (상대가 있어 정지 불가)
- 카드: 연사/위력/확산/관통/기동/자가 수복/장갑/대시 강화/회수/피해 감쇠/전리품 탐지/충격파 공명/코어 정비 — 13계통 × 4등급. **레전드까지 완료한 계통은 풀에서 제외**되고, 전 계통 만렙이면 카드가 더 나오지 않음
- 30초 미선택 시 첫 카드 자동 선택

### ✦ 시너지 (조합 각성)
특정 카드 **2계통을 모두** 획득하면 각성하고, 이후 **두 계통의 티어가 오를 때마다 효과가 누적**된다 (최대 티어합 8).
**시너지 등급** = 두 계통 티어 중 낮은 쪽 **+1**: 기본+기본 → **레어** 시너지, 레어+레어 → **에픽**, 에픽+에픽 이상 → **레전드**. 등급이 오를 때마다 효과가 누적된다. 화면 하단 **'▲ 증강 n · ✦ 시너지 n' 칩**을 누르면 보유 증강·시너지 상세(티어·등급·누적 효과)가 시트로 열린다.

| 시너지 | 조합 | 등급 효과 (레어/에픽/레전드 도달 시 누적) | |
|---|---|---|---|
| 폭풍 사격 | 연사 + 확산 | 연사 +10% / +12% / +15% |
| 철갑 관통 | 위력 + 관통 | 각성 관통 +1 · 피해 +8/10/12%, 레전드 관통 +1 |
| 전투 기동 | 기동 + 자가 수복 | 대시 쿨 −8/−10/−12% |
| 재생 장갑 | 장갑 + 자가 수복 | 수복 +1/+1.5/+2.5 |
| 약탈 프로토콜 | 회수 + 위력 | 자원 +10/12/15% |
| 불괴 장갑 | 피해 감쇠 + 장갑 | 받는 피해 −5/−6/−8% |
| 성역 프로토콜 | 코어 정비 + 자가 수복 | 코어 +60/+90/+150 |
| 전리품 사냥꾼 | 전리품 탐지 + 회수 | 드랍 +15/20/30% · 자원 +5%씩 |
| 수호자 서약 | 피해 감쇠 + 코어 정비 | 받는 피해 −3/−4/−5% · 코어 +25/35/50 |
| 공명 폭발 | 충격파 공명 + 위력 | 충격파 피해 +8%씩 · 레어 둔화 30% → 에픽 40%+마비 20% → 레전드 50%+마비 35% |
| 연쇄 기동 | 충격파 공명 + 기동 | 충격파 쿨 −6/−8/−10% · 범위 +6%씩 |

### 연구 (연구 버튼, 본인 지갑 차감)
캐릭터(HP/이속/공격력/**사거리**) · 스킬(충격파/대시) · 구조물(벽 내구/포탑 화력/건설 비용/**코어 수리 +150**). **모든 연구는 개인 단위** — 구조물 연구는 내가 지은 벽·포탑에만 적용된다.

## 자원

- 위치: **좌상단 패널 하단 앰버색 ◈ 숫자** — 획득/사용 시 펄스
- 획득: 처치(유형별 2~30) + 웨이브 클리어 보너스(30+12×웨이브)
- **각자의 지갑** — 처치 골드는 **두 유닛 모두**에게 지급되며 각자 자기 회수 배율 적용. 웨이브 보너스도 각자 지급. 연구도 전부 개인 단위

## 기록 · 이어하기 (솔로)

- 매 준비 단계 진입 시 자동 저장 — 중도 이탈해도 로비 SOLO 카드의 **"이어하기"** 버튼으로 해당 웨이브 준비부터 재개 (스탯·증강·구조물·자원 유지)
- 게임 종료 시 저장은 삭제되고 **내 기록**(최고 웨이브·승/판)이 갱신되어 SOLO 카드에 표시
- 저장은 브라우저 localStorage — 기기별 보관

## 필드 아이템 (E / 아이템 버튼)

융단 폭격(광역 90) · 즉석 포탑(75% 선건설) · 응급 키트(완전 회복) · 지연 필드(5초 감속)

- **인벤토리 5칸** — 주우면 자동 보관, 가득 차면 바닥에 남음
- E 키 또는 아이템 버튼 → 인벤토리 레이어에서 원하는 아이템 선택 사용

## 악몽 난이도

- **웨이브 1~3은 어려움과 동일** — 이후 점점 조여온다
- 웨이브 4부터 균열이 **동시에 여러 개** 열린다 (싱글 2개, 멀티 4개 전부)
- 웨이브 6부터 풀 악몽: 몹 수 어려움의 2배 · 피해 +10% · 스폰 2배 속도
- 불가능에 가까운 난이도 — 멀티 협동 플레이 권장


## 침투 작전 (파이널)

- 15웨이브 클리어 시 승리 대신 **적의 코어로 통하는 균열**(금색)이 무작위 방향에 열린다 — 진입하면 시작
- **연구·증강·자금은 그대로 유지** — 구조물만 가져갈 수 없어 **자동 매각**(현 시세 70%)되어 건축자에게 자원으로 지급된다. "PHASE 2 — 균열 침투" 카운트다운과 함께 전환
- 맵 2: 세로 회랑, 미니맵 없음, **코어가 하단 시작 지점으로 이설**(파괴되면 패배), 하단 스타트 — 위에서 15웨이브의 **2배 물량** + 중간·대형 보스 순차 출현
- 전멸시키면 암전 점멸 후 **침식의 근원** 등장: 최종 보스 체력의 10배 · 2배 크기
- 처치 시 최종 클리어 + 엔딩 크레딧. 침투는 편도 — 저장 없음
